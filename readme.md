# No Graphics - Metal

A C-compatible implementation of the [_No Graphics API_](https://www.sebastianaaltonen.com/blog/no-graphics-api) built on top of _Metal 4_ and C++.

The complete API can be found [here](include/gpu/gpu.h). Examples can be found [here](examples).

## Device support
The project requires an Apple device supporting the Metal 4 API. Macs with Apple Silicon running macOS Tahoe or later are supported.

# Project status
This project is discontinued. An updated version re-written in Odin with support for both _Metal 3_ and _Vulkan 1.2_ can be found [here](https://github.com/vicixdev/hal).
